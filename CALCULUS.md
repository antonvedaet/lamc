λ-исчесление
---

Кучка теории которая мне нужна для интерпритатора, тут немного несуразные пояснения, так что готовится к зачетам по ней не рекомендую.

---
Термы:
```
x - переменная
λx. M - абстракция
M N - апликация, где M, N - сами по себе λ-термы
```
#### Абстракция
λx. M - примерно означает: Функция принимающая x и возвращающая терм M. 
#### Апликация
M N - применить M к N

---
Апликация левоассоциативная

`x y z -> (x y) z`

Абстракция захватывает все выражение справа

`λx. m n -> λx. (m n)`

`λx. λy. m -> λx. (λy. m)`

---
#### Переменные

Два вида: связанные и свободные

Связанные - находятся в области действия абстракции

`λx. x` - x связанная переменная

`λx. y` - y свободная переменная

Свободные переменные - это те, которые не находятся в области действия абстракции. Они могут быть заменены на другие термы.

`λx. x y` - x связанная, y свободная

`λx. λy. x y` - x и y связаны

Так же вот такой момент:

`λx. (λx. x) x`

Хоть здесь переменные оба раза x но это не один и тот же x. Это две разные переменные.
Если перевести на обычный язык по типу C это что то в духе:
```C
void f(int x) {
    void g(int x) {
        return x;
    }
    return g(x);
}
```
т.е внутренний x не имеет никакого отношения к внешнему x. Внутренний x связан с абстракцией λx. x, а внешний x связан с абстракцией λx. (λx. x) x

---
#### α-эквивалентность

`λx. x` и `λy. y` - это α-эквивалентные термы

`λx. λy. x y` и `λa. λb. a b` - тоже α-эквивалентные термы

Важно то что свободные переменные не должны быть переименованы, так как это изменит смысл терма. Например:

`λx. x y` и `λy. y y` - не α-эквивалентные термы, так как в первом терме y свободная переменная, а во втором терме y связанная переменная.

Грубо говоря α-конверсия - процесс замены связанных переменных на другой набор связанных переменных, сути  абстракции не меняет вообще просто предотвращает повторы имены.

#### β-редукция

`(λx. M) N -> M[x := N]` - все вхождения x в теле M заменены на терм N

На псевдокоде:
```
M = x + x * 2
N = 3
(λx. M) N -> 3 + 3 * 2

или 

(λx. x + x * 2) 3 -> 3 + 3 * 2
```
Это и те самые "исчесления" в лямбда-исчеслении. Такие выражения называются редексами/redex. 

#### η-редукция
подмножество β-редукции

`λx. M x -> M` - если x не является свободной переменной в M.

Ну то есть ранее упомянутый:
`λx. (λx. x) x -> λx. x`

НО

`λx. (λx. x) y -> λx. y` - тут уже не η-редукция, так как y является свободной переменной в терме (λx. x) y. Это обычная β-редукция.

---
Это вся базовая теория которая впринципе нужна для интерпритатора, но дополнительно я здесь опишу данные в λ-исчеслениях, так как казалось бы примитивов которые представляют из себя данные здесь вообще нету, но без данных λ-исчесление не имело бы никакого смысла и было бы в целом бесполезном. Соответственно их надо как то кодировать в термы. Методов бесконечное множество.

Числа Черча

`0 = λf. λx. x` - здесь например вообще нету апликации это функция принимающая f и возвращающая функцию принимающу x и возвращающую x. Т.е функция применена к переменной x 0 раз.

`1 = λf. λx. f x`

`2 = λf. λx. f (f x)`

`3 = λf. λx. f (f (f x))`

и т.д

Это метод описания данных, суть которого заключается в том чтобы кодировать число n функцией которая применяется n-раз к аргументу.
